# ClassGod

**Локальный инструмент экстренного переключения контекста и управления рабочим столом для macOS. Одно сочетание клавиш возвращает нужную вкладку, приложение или безопасное рабочее пространство.**

## Что такое ClassGod

ClassGod работает в строке меню macOS. Сохраните адрес браузера и назначьте глобальное сочетание: приложение активирует подходящую вкладку или заново откроет сохранённый URL, если вкладка была закрыта.

Также доступны локальный буфер обмена, переключение приложений, защищённые режимы браузера, нативные виджеты, управление вентиляторами, монитор активности, динамические обои и центр разрешений. Данные остаются на Mac, необязательные разрешения можно пропустить, а привилегированные действия всегда требуют явного согласия пользователя.

## Основные возможности

| Модуль | Возможность |
| --- | --- |
| **DestinTab** | Сохраняет адреса Safari, Chrome и Edge; поддерживает поиск, сортировку, закрепление, групповые действия и отдельные сочетания. |
| **SuperSwitch** | Активирует или запускает выбранные приложения и цели глобальными сочетаниями клавиш. |
| **Fake Lock** | Открывает браузер и URL в режиме Safe Browser или MapTest Bypass с раздельной блокировкой переходов назад и вперёд. |
| **Clipo** | Локальная история буфера обмена, быстрые слоты, поиск, закрепление, импорт/экспорт и управляемое хранение. |
| **Permission Center** | Показывает актуальное состояние, назначение, способ проверки и точную страницу настроек каждого поддерживаемого разрешения. |
| **Fan Control** | Читает доступные температуры и данные вентиляторов; предлагает режимы System, Max, Manual и Custom. Привилегированный Helper работает только после одобрения. |
| **Widgets** | 19 нативных виджетов WidgetKit для системы, погоды, заметок, задач, файлов, терминала и запуска приложений. |
| **Инструменты рабочего стола** | Activity Monitor, динамические обои, Hacker Desktop, Error Hub, BrowserBypasser и инструменты AssessPrep. |

## Конфиденциальность

- Нет аналитики, телеметрии, учётных записей, серверной части ClassGod или фоновой отправки данных.
- Настройки, вкладки, история буфера, данные виджетов и медиаконфигурация хранятся локально.
- Состояния разрешений читаются из macOS и отображаются локально.
- Необязательные разрешения можно пропустить; связанные функции безопасно ограничиваются.
- После двух подтверждений полное удаление очищает данные, Helper, LaunchDaemon, установочные квитанции и решения macOS о разрешениях ClassGod.

## Требования

- macOS 14.0 или новее
- Текущие сборки предназначены для Apple Silicon (`arm64`)
- Safari, Google Chrome или Microsoft Edge
- Универсальный доступ и Автоматизация для основного сценария браузера
- Права администратора могут потребоваться для PKG, Helper управления вентиляторами или полного удаления

## Установка

Откройте DMG и перетащите **ClassGod** в **Applications** либо запустите PKG для установки в `/Applications`. При первом запуске мастер разрешений можно завершить или временно пропустить.

Текущие публичные файлы подписаны ad-hoc и не нотарифицированы Apple. При первом запуске может потребоваться **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. Устанавливайте только файлы с проверяемым источником и контрольной суммой.

## Быстрый старт

1. Запустите ClassGod и дождитесь открытия главной панели после фирменной анимации.
2. Разрешите Универсальный доступ и автоматизацию браузера для основной функции. Необязательные разрешения можно пропустить.
3. Откройте **DestinTab**, сохраните текущую вкладку и запишите сочетание клавиш.
4. Нажмите сочетание из любого приложения, чтобы активировать вкладку или заново открыть сохранённый URL.

Поддерживаются буквы, цифры и F1–F12; доступные модификаторы — Command, Option, Control и Shift.

## Границы разрешений

Разрешения конфиденциальности macOS выдаёт сам пользователь. DMG, PKG, приложение, скрипт или привилегированный Helper не могут принять запрос TCC от его имени.

| Уровень | Примеры | Поведение |
| --- | --- | --- |
| **Основной** | Универсальный доступ, Автоматизация | Обнаружение и управление поддерживаемыми браузерами. |
| **Рекомендуемый** | Мониторинг ввода, запись экрана, уведомления, полный доступ к диску | Включает соответствующие сочетания, захват, оповещения и локальные файловые операции. |
| **Необязательный** | Камера, микрофон, фото, геолокация, контакты, календарь, напоминания, Bluetooth, распознавание речи, локальная сеть | Запрашивается только для соответствующей функции и может быть пропущен. |

## Сборка из исходного кода

```bash
git clone https://github.com/hzagaming/ClassGod.git
cd ClassGod
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild -project ClassGod/ClassGod.xcodeproj \
  -scheme ClassGod \
  -destination 'platform=macOS' \
  build
```

Приложение использует SwiftUI + AppKit + MVVM. Этап сборки Xcode компилирует и встраивает `ClassGodHelper`. App Sandbox намеренно отключён из-за AppleEvents, Универсального доступа, управления обоями и одобренного пользователем Helper.

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild -project ClassGod/ClassGod.xcodeproj \
  -scheme ClassGod \
  -destination 'platform=macOS' \
  test

cd ClassGodHelper && DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun swift test
```
